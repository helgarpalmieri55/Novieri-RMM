# Licenses (SAM) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Licenses / Software-Asset-Management module — a license catalog reconciled against inventory installs, with sealed keys, allocation, a compliance sweep, and reporting.

**Architecture:** Control-plane-only module mirroring `app.modules.change_mgmt` / `app.modules.bcp` (models → schema → errors → service(s) → reporting → api → registration), plus one Celery-beat sweep (mirrors `app.worker` sweeps) and reuse of `app.core.vault` for key sealing. Introduces the shared `vendor` entity.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2 (async/asyncpg), Alembic, Pydantic v2, Celery+Redis; React+TS+Vite+vitest frontend.

## Global Constraints

- **Spec:** `docs/modules/licenses/spec.md` is authoritative. Read the relevant section before each task.
- **Control-plane only:** no agent capability, no job types, no gateway edit. `register(app)` mounts the router only. The ONE worker addition is the compliance sweep (Task 10).
- **Migration** is the next in sequence — resolve the current head with `alembic heads` in Task 1 (expected `0018`); never hard-code a revision elsewhere. Downgrade uses valid Postgres only (`DROP TABLE IF EXISTS ...`, `DROP INDEX IF EXISTS <name>` — no MySQL `... ON table`).
- **Tenancy (invariant #5):** every table RLS `ENABLE + FORCE` + `tenant_isolation` policy (USING + WITH CHECK, `org_id = current_setting('app.current_org', true)::uuid`); every query carries an explicit `org_id` predicate; every cross-reference resolved `WHERE org_id AND id`, cross-org id rejected as `LicenseNotFoundError`/`LicenseValidationError` (indistinguishable from nonexistent).
- **RBAC (invariant #6):** three perms `licenses.read` / `licenses.manage` / `licenses.keys.read`. Migration grants: super + org-admin = all three; **technician = read + manage (NOT keys.read)**; auditor + read-only = read. `app/core/rbac.py` `PERMISSIONS` gains all three AND `tests/test_rbac.py` + `tests/test_api_routes.py` perm-sets are updated in Task 11 (Phase-7 lesson).
- **Secrets (invariant #3):** license keys sealed via `app.core.vault` `seal_bytes(session, org_id, bytes) -> str` / `open_bytes(session, org_id, str) -> bytes`; never in list/detail responses (`has_key: bool` only), never logged. Reveal is a dedicated audited route.
- **Audit (invariant #4):** entitlement changes, allocation create/release, key reveal, vendor/product create/update, review-queue map/ignore, CSV export are audited (`actor_type="user"`); the sweep writes snapshots as data, not audit. **No-audit-on-view** for lists/detail/compliance/renewal/cost reports.
- **Errors:** `LicenseNotFoundError(LicenseValidationError)`; API maps NotFound→404, other validation→400 by `isinstance`, never message-string, never 500 (Phase-9 lesson).
- **Currency:** per-record `cost` + `currency` (ISO-4217); no FX, no cross-currency sum (Phase-13/Budget owns FX).
- **Tenancy tests:** where a cross-org guard exists, include an RLS-bypassing admin-session test that makes the app-level `org_id` predicate the sole guard, mutation-verified (Phase-10 lesson).
- **Frontend:** state/vocab strings sourced verbatim from backend (Phase-5 lesson); strict TS, no `any`.
- **Verification:** every task ends `.venv/bin/python -m pytest` (task tests) + `.venv/bin/mypy <changed>` + `.venv/bin/ruff check <changed>` clean; Task 11 runs the FULL backend suite; Task 12 runs `npm test`/`typecheck`/`build`.
- **Commit** signature trailer style matches the repo; one commit per task (fixes amend/append).

**Interfaces:**
- `matching.py`:
  - `def rule_matches(rule: dict, name: str, publisher: str) -> bool` — case-insensitive exact/prefix/regex on `name`; if `rule["publisher"]` set, require case-insensitive publisher equality. (Matching in Python — keeps the regex out of SQL and the tenant boundary in one predicate.)
